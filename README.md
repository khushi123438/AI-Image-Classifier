# 🧠 CNN Vision AI - Animal Image Classifier

A Deep Learning based **Animal Image Classification Dashboard** built using a Convolutional Neural Network (CNN).  
The application allows users to upload animal images and get real-time predictions with confidence scores through an interactive web dashboard.

## 🚀 Project Overview

CNN Vision AI uses a trained CNN model to classify animal images into different categories.  
The project demonstrates the complete pipeline of a Computer Vision application — from dataset preparation and model training to web deployment.

## ✨ Features

- 📷 Upload animal images
- 🔍 Image preview before prediction
- 🧠 CNN-based image classification
- 📊 Prediction confidence score
- 🌐 Flask-powered web application
- 🎨 Interactive AI analysis dashboard

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Deep Learning:** TensorFlow, Keras
- **Model:** Convolutional Neural Network (CNN)
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Dataset:** Kaggle Animal Image Dataset

## 🧠 Model Workflow

1. Dataset collection from Kaggle
2. Image preprocessing and normalization
3. Data augmentation for better generalization
4. CNN model training
5. Model evaluation
6. Integration with Flask web application

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/khushi123438/AI-Image-Classifier.git

Install dependencies:

pip install -r requirements.txt
```

Run the application:

```
python app.py
```

Open in browser:

```
http://127.0.0.1:5000
```
